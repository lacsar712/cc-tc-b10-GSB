# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 夜间提醒

页眉进「夜间提醒」专页，设夜间时段、低样本阈值、近窗时长，并看提醒流水。

- 判定用服务端时钟：此刻落在夜间时段**且**近窗办结低于阈值，提醒灯才亮，并由灭转亮时记一条提醒履历。
- 提醒仅提示值班，**不拦截写口**：白天交单、夜间交单都照常放行；拱顶二衬龄期不足时这条提醒仍只是提醒。
- 测量员可改设置；巡检员只读阈值与提醒履历。
- 自检：把夜间窗调到盖住现在并清掉近窗办结（或调高阈值）应看见灯亮并记下履历；把窗挪到白班灯应熄灭。

接口：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/night-reminder` | 当前判定（服务端时间、是否在夜间窗、近窗办结数、灯态）与设置 |
| PUT | `/api/night-reminder` | 改夜间时段/阈值/近窗时长（仅测量员），保存即按新设置重判 |
| GET | `/api/night-reminder/events` | 提醒流水（最近 200 条） |

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
